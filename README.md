# MNIST_PROJECT
Data Loading and Preprocessing: Loading the MNIST dataset, flattening images, and normalizing pixel values.
Model Definition: Constructing a two-layer fully connected neural network.
Loss Function and Optimizer: Defining the cross-entropy loss and using Stochastic Gradient Descent (SGD) for optimization.
Training Loop: Iteratively training the model on mini-batches of data.
Evaluation: Testing the model's accuracy on the test set.
Prediction Visualization: Displaying example predictions with their corresponding images.
